# PopX React App (Educase Assignment)

## 📌 Project Description
This is a React JS internship assignment built for Educase.  
It includes Signup, Login, and Profile screens with localStorage authentication.

---

## 🚀 Features
- Landing Page
- Signup Page
- Login Page
- Profile Page
- React Router navigation
- Form handling
- localStorage authentication
- Logout functionality

---

## 🛠 Tech Stack
- React JS
- Vite
- Tailwind CSS
- React Router DOM
